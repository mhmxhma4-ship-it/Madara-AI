# Madara AI

A mobile-first AI Roblox game builder.

## Current status

This repository contains the initial Next.js 15 + TypeScript + Tailwind starter and the first responsive Madara AI creation screen.

## Run locally

```bash
npm install
npm run dev
```

## Environment variables

AI provider keys and Roblox Open Cloud credentials must be stored only as server-side environment variables. Never expose secrets in browser code or commit them to Git.
